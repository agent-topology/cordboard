cordboard ADR-0002 보조 문서 같은 단어, 다른 뜻

이 단어,
누구 말인가

OTel · LangGraph · LangChain · Langfuse · DeepAgents · Agent Protocol · LiteLLM · A2A · redact-secret. 아홉 개 출처가 같은 단어를 다르게 쓴다. 여기 없는 단어는 안전하다.

catch 01

Rule이 정면 충돌한다

Langfuse의 Rule도 "필터 + 트리거"다. 같은 프로젝트에서 "룰 추가해"가 통하지 않는다.

→ cordboard 문서에서 Rule은 항상 cord.Rule. Langfuse 것은 lf.Rule

catch 02

우리가 금지어를 썼다

chain을 금지어로 지정해 놓고 cord.chain.depth에 넣었다. LangChain과 Langfuse 양쪽과 부딪힌다.

→ Cascade Depth / cord.cascade.depth 로 개명

catch 03

Signal도 안전하지 않았다

OTel이 traces·metrics·logs를 "signals"라 부른다. "아무와도 충돌 안 함"은 틀린 판단이었다.

→ 이름은 유지. 대신 충돌 목록에 올리고 텔레메트리 얘기 중엔 항상 수식

수식 규칙 — <source>.<word>

접두사는 신호이지 장식이 아니다. 전부 붙이면 아무 의미도 없어진다.

언제 붙이나

  1. 충돌 목록에 있는 단어는 항상. 아래 목록이 그 목록이다
  2. cordboard 문서 안에서 cord.는 생략 가능. 기본 네임스페이스이므로. 단 같은 문단에 남의 것이 함께 나오면 붙인다
  3. 충돌 없는 단어에는 붙이지 않는다. otel.Collector는 과잉이다 — Collector는 하나뿐이다
  4. 금지어는 수식해도 우리 도메인 명사가 되지 않는다. lf.Event는 남의 것을 가리킬 때만 쓴다
  5. 코드에서는 속성 접두사가 이미 그 일을 한다. cord.tier에 또 붙이지 않는다

출처 접두사

cord.우리 것 — 기본 네임스페이스 otel.OpenTelemetry (SDK · Collector · semconv) lf.Langfuse lg.LangGraph lc.LangChain ap.Agent Protocol / Aegra da.DeepAgents llm.LiteLLM a2a.A2A Agent Card ss.redact-secret wb.workbench (선례)

사전

붉은 항목은 같은 문맥에서 다르게 쓰이는 위험한 단어. 황토는 문맥이 달라 덜 부딪히는 것. 회색은 참고용 — 충돌이 없다.

해당하는 항목이 없습니다.

ADR-0002(어휘)의 보조 문서. 충돌 항목이 추가되면 ADR도 함께 갱신한다. 여기 없는 단어는 안전하다는 뜻이므로, 새 의존성을 채택할 때 이 목록을 먼저 훑는다.
