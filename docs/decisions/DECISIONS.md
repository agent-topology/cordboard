## 슬라이스 0에 필요한 것 — 전부 작성됨

슬라이스 0은 위험 1(어휘가 질의에 답하는가)과 위험 2(마스킹 관문이 작동하는가)를 시험한다.
그 과정에서 **되돌리기 어렵게 못 박히는 것은 셋**이고, 넷째는 슬라이스 0이 실제로 사용한다.

| ADR | 슬라이스 0에서 못 박히는 것 | 시험하는 작업 |
|---|---|---|
| **0008** | span 트리 모양 — Attempt가 자식 span이고 `escalated`가 선언된다 | 작업 3 (관문) |
| **0005** | 아카이브 포맷 — raw OTLP JSONL, 이것이 기록의 원본 | 작업 2 · 3 |
| **0006** | 마스킹 지점 — 프로세스 안에서 지우고 Collector가 검문. **redact-secret 릴리스 선행** | 작업 2 · 종료 판정 ②③ |
| **0004** | Tier↔Model 분리, 승격은 그래프 소유 | 작업 4 |

셋이 append-only 아카이브에 구조로 남기 때문에, **데이터가 다섯 줄일 때 확정해야 하고 그 뒤로는 마이그레이션이 된다.**
슬라이스 0 작업 3이 "Attempt 계층을 일부러 잘못 만들어 보고 질의가 깨지는 걸 확인한다"까지 포함하는 이유다.

## 작성 과정에서 드러난 것

**0001은 논거가 틀렸다.** "경계를 OS가 강제한다"는 원칙이었는데, 경계가 둘이었고 이 프로젝트의 테제인 경계 1은 계약이 지키지 프로세스가 지키지 않는다. 결론은 유지되지만 원칙에서 기본값으로 강등됐고, 원래 검토에서 빠져 있던 지연 기동이 슬라이스 3으로 들어갔다.

**0008은 분류가 틀렸다.** 처음에 "어휘 결정이라 ADR 불필요"로 뒀는데, 실제로는 아카이브의 물리적 구조를 정하는 결정이었다.

**0002는 두 번 틀렸다.** 처음엔 "ADR 불필요"로 분류했고(0008과 같은 이유로 틀렸다), 그다음엔 **방향이 틀렸다** — 겹치는 단어를 금지어로 처리했는데, 그게 자연스러운 표현을 막고 이해를 개선하지 않는 순수한 마찰이었다. 금지를 걷어내고 매핑으로 대체했다.

핵심은 이 구분이다 — **데이터에 굳는 이름**(속성 키, 닫힌 목록 값)에서는 정밀함이 값을 하고, **사람이 말할 때 쓰는 단어**에서는 문맥이 해결한다. 첫 판은 전자의 해법을 후자에 확장했다.

**0006은 전제가 바뀌었다.** 첫 판은 "패턴 목록을 직접 관리한다"를 전제로 썼는데, 같은 저자의 `redact-secret`이 이미 그 구조를 갖추고 있었고 Rust 코어 마이그레이션으로 언어 장벽까지 사라졌다. 전면 재작성했다.

ADR을 쓰는 값이 결정을 기록하는 데만 있는 게 아니라는 증거가 다섯 건 나왔다. 그중 하나(0002)는 결정 자체가 뒤집혔다.

## 외부 의존 — 순서가 정해졌다

ADR-0006이 `omiologic/redact-secret`의 **Rust 코어 마이그레이션과 PyO3 바인딩 릴리스**를 전제한다.
그리고 그쪽을 먼저 하기로 정했다. cordboard 슬라이스 0은 그때까지 막힌다.

임시 리댁터로 cordboard를 먼저 걷게 하는 선택지가 있었지만, 임시 코드가 영구가 되는 걸 피하고
ADR-0006을 한 번만 쓰기 위해 순서를 이렇게 잡았다.

**redact-secret 쪽에서 시간 순서상 가장 급한 것** — TS 코어를 제거하는 이슈(#72)보다
적합성 픽스처를 독립 데이터로 빼내는 일이 먼저다. 묶여 있으면 Rust 구현의 정답지가 같이 사라진다.

## cordboard는 두 업스트림 프로젝트의 첫 고객이다

우회를 만들지 않는다. 겪은 것은 [업스트림 요구사항 문서](cordboard-upstream-requirements.md)에 모아
이슈로 올린다. 우회 코드를 만들면 두 번 손해다 — 코드가 남고, 스펙은 그 요구를 못 듣는다.

**현재 열린 항목** — AT-1(depth≥1에서 부모 노드 소실, 🔴), AT-2(sentinel 판별이 코어에 없음),
AT-3(`direct` 팬아웃의 병렬 의미), AT-4(`joins` 정의), AT-5(그래프 이름 소유권),
AT-6(LangGraph 지원 범위), RS-1(SpanProcessor 통합 패턴), RS-2(`block` 호출자 계약).

**실측된 좋은 신호** — `agent-topology` beta.1 → beta.2에서 같은 그래프의 `structureHash`가
동일했다(`d0b436…`). 포맷이 두 릴리스를 건너 안정적이었다는 증거다.

## 외부 프로젝트 두 개가 실물이 됐다 (2026-09-10)

| | 상태 | cordboard에 미치는 영향 |
|---|---|---|
| [`agent-topology`](https://github.com/agent-topology/agent-topology) | **0.1 public preview.** PyPI 2 + npm 2 패키지, Python·TypeScript 생산자, 정본 JSON Schema | ADR-0009 · 0011 · 0012 갱신 |
| [`redact-secret`](https://github.com/redact-secret/redact-secret) | Rust 코어 완료, PyO3·N-API·WASM 바인딩. 릴리스 승인 대기 | ADR-0006 갱신 |

**셋이 결정을 실제로 바꿨다.**

**① R3가 두 번째 타격을 받았다 (0007).** `agent-topology` 0.1은 여러 목적지가 **대안인지 전부 실행되는지 확립하지 않는다.**
R3은 "병렬 분기 안의 인터럽트"를 찾는 규칙이라 코어 문서만으로 구현할 수 없다.
→ **R3은 LangGraph 전용 규칙**이 되고, 거부 조건 1을 두 군데서 못 넘는다. 예외로 유지하되 선례로 삼지 않는다.

**② 커스텀 detector가 불가능하다 (0006).** 모든 detector는 Rust 코어에서 돌고 바인딩은 새 구현을 만들 수 없다.
`redaction.extra_patterns` 계획이 폐기됐다. 반면 **기본 정책이 우리가 쓰려던 표와 같아서** cordboard는 정책을 정의하지 않는다.

**③ LangGraph 버전이 묶인다 (0001).** 생산자가 검증된 좁은 범위만 지원한다.
"그래프마다 자기 의존성"이라는 약속에 구멍이 생겼다 — 파이썬 버전은 달라도 되지만 LangGraph 버전은 공통 범위 안이어야 한다.

그리고 두 프로젝트가 내 프로토타입보다 나은 점 둘을 기록해 둔다.
**픽스처가 언어 중립 `fixture.json` 레시피**라는 것, 그리고 **`gaps`와 `producerLimitations`의 분리** —
내 설계는 항상 존재하는 한계를 gap에 넣어서 모든 문서를 영구히 incomplete로 만들었을 것이다.

## 코드가 문서를 고친 첫 사례

`agent-topology`의 LangGraph 생산자를 실제로 만들어 돌린 결과가 ADR 셋을 고쳤다.
설계만으로는 안 나왔을 것들이다.

| 발견 | 고쳐진 곳 |
|---|---|
| 정적 인터럽트는 `node.metadata`에서 파생되지만 **동적 `interrupt()`는 전혀 안 보인다** | **0007** — R3에 사각지대가 생겼다. 정적만 거부, 동적은 선언에 의존 |
| 조건부 라벨이 `edge.data`에 살아 있다 | 0011 — 뷰어가 분기 이유를 표시할 수 있다 |
| path map 없는 조건부 엣지는 목적지가 빠지는 게 아니라 **가짜 엣지를 만든다** | 0011 — `ORPHANED_NODES` 갭이 탐지 신호 |
| 소스 해시보다 **구조 해시**가 표류 검사에 맞다 | 0011 — 주석·공백 변경으로 오탐이 안 난다 |

0011의 Action Item 1·2·3이 이 과정에서 닫혔다.

## 최소 실행 계약 검증 (2026-09-11, #4)

[최소 그래프](../minimal-graph.md)는 Python 3.12/uv/pytest로 실행된다.
ADR-0004·0008의 예제를 `fast/failed → fast/escalated → deep/passed`로 정정했다.
승격은 정확히 1회이며 같은 Tier 재시도는 승격이 아니다.
`passed`·`repaired`·최종 `failed`, 필수 Subject, 실행별 독립 상태를 검증한다.
이 작업은 고정 응답과 메모리 내 기록만 사용한다. 위 마스킹 선행 조건을 변경하거나
Collector·아카이브 관문을 완료한 것이 아니다.
